이차함수 탐험기

중학교 3학년 · 변화와 관계 · M9-CR-03 — 슬라이더를 움직여 \(a, b, c\)가 그래프에 어떻게 영향을 주는지 확인해 보세요

꼭짓점 좌표
(0, 0)
대칭축
x = 0
판별식 \(D = b² - 4ac\)
D = 0 (실근 1개)
a (이차항 계수) 1.00
b (일차항 계수) 0.00
c (상수항) 0.00
왜 이렇게 되는가?

a의 역할: 그래프의 모양을 결정해요. a > 0이면 아래로 볼록(U자), a < 0이면 위로 볼록(∩자). \|a\|가 클수록 폭이 좁아지고, 작을수록 완만해져요.

b의 역할: 꼭짓점의 x좌표를 좌우로 이동시켜요. 꼭짓점의 x좌표는 \(-\frac{b}{2a}\)로 계산되죠.

c의 역할: y축과 만나는 점이에요. x = 0을 대입하면 y = c가 되니까요.

판별식 D: x축과 몇 번 만나는지 알려줘요. D > 0이면 두 점, D = 0이면 한 점(접함), D < 0이면 만나지 않습니다.
