## 핵심 원칙 (3대 원칙)

1. **데이터 정직성**: 단원 정보는 NCIC 원문 기준. 추측·할루시네이션 금지.
2. **저작권 안전**: 디즈니/픽사/지브리/마블/만화/노래가사·문학 작품 본문 인용 금지.
3. **본질 우선**: 화려함보다 개념의 핵심이 보이는 시각화.

## 우선순위 (전체)

- **Phase 1 (P0, ~350개)**: 초중등 핵심 + 고등 공통 + 고등 일반선택 핵심
- **Phase 2 (P1, ~250개)**: 고등 진로선택·융합선택, 학습 경로 그래프, 진도 트래커
- **Phase 3 (P2)**: 평가 모듈, 게임화, 학습 분석

## 권장 양산 순서 (조카 학년 미정 대응)

1. **공용 기본기** (어느 학년이든 도움): 분수 시각화, 영어 시제, 한국사 타임라인, 입자 모형, 수요공급
2. **초3~중3 P0 전 단원** (~150개)
3. **고등 공통 과목** (~62개, 1학년 필수)
4. **고등 일반선택** (~50~80개, 수능·교양 핵심)
5. **고등 진로·융합선택** (학습자 관심사에 따라 선별)
