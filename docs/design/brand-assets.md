# Brand Assets

**Last Updated:** 2026-05-21

## Usage Rules

- 캐릭터는 학습 행동을 설명하는 보조 시각 신호로만 쓴다.
- 한 화면에 큰 캐릭터는 1개만 둔다.
- 버튼이나 작은 라벨 안에는 캐릭터 이미지를 넣지 않는다.
- 기본 배경은 white/off-white로 유지하고, 캐릭터 주변에 과한 그림자나 장식 효과를 추가하지 않는다.
- 다크 모드에서는 캐릭터가 흰 배경 박스로 보일 수 있으므로, 핵심 화면의 최종 Figma 기준은 Light Theme로 잡는다.
- 로고 텍스트는 `하루배움`을 기준으로 하며, 설명형 제품명은 보조 문장에 둔다.

## Product Fit

`하루배움`은 26초식 오늘 큐 UX와 잘 맞는다. 홈은 전체 392개 단원을 먼저 보여주기보다, 오늘 할 개념과 복습 큐를 먼저 보여준다. 캐릭터는 “하루 하나만 해도 전진한다”는 감각을 만드는 데 사용한다.
