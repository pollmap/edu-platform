## 패턴 01. 슬라이더 → 그래프 연동 (★★★★★ 가장 많이 쓰임)

### 핵심 구조
```
[슬라이더 1] [슬라이더 2] [슬라이더 3]
       ↓ (실시간)
[그래프/시각화]
       ↓
[수식/값 표시]
[해석 텍스트 (왜 이렇게 되는가)]
```

### 표준 props
```typescript
interface SliderToGraphProps {
  variables: Array<{
    name: string;
    label: string;       // '기울기 a'
    min: number;
    max: number;
    step: number;
    initial: number;
  }>;
  formula: (vars: Record<string, number>) => string;  // KaTeX 문자열
  computePoints: (vars: Record<string, number>) => Array<{x: number; y: number}>;
  domain?: [number, number];
  range?: [number, number];
  interpretation?: (vars: Record<string, number>) => string;
}
```

### 적용 단원
- M8-CR-04 일차함수 (a, b)
- M9-CR-03 이차함수 (a, b, c) ← **샘플 작성**
- M9-GM-01 삼각비 (각도)
- H8-SO-02 수요·공급 (수요량, 공급량)
- S5-MA-02 산과 염기 (pH 0~14)

### 핵심 구조
```
[알고리즘 결과 미리보기]
```

```typescript

    explanation: string;        // 해설
    highlight?: string;         // 강조할 부분의 ID
  }>;
  autoplay?: boolean;
  speed?: number;
}
```

## 공통 디자인 원칙

1. **즉시 반응**: 입력 변경 시 100ms 이내 결과 반영
2. **되돌리기**: Reset 버튼 항상 우측 상단
3. **모바일 우선**: 슬라이더는 손가락으로 잡을 수 있는 크기 (최소 44px)
